# AI usage

I used Claude Code as my main assistant, starting in Plan Mode: from the PDF it listed the explicit and implicit requirements, and we settled the architecture and the decisions in `DECISIONS.md` before any code was written. Claude then wrote most of the code, tests and drafts of these documents under my direction, with Claude skills for focused passes (`frontend-design` for the FINQ-style UI, `code-review` for independent reviews whose findings I verified before fixing). GitHub Copilot made a few smaller edits, and I used Google Gemini to cross-check some decisions and wording. I made the calls (PostgreSQL, Pinia, shadcn-vue, the validation rules, what to cut), reviewed every file, and ran the app and all three test suites myself. Before submitting I rewrote the commit history into topic-sized commits, so it shows the final structure rather than the order the work happened in.
